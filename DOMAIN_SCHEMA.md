# Domain: Rental Housing Listings

## Entity: RentalListing

- **Primary field**: `address` — the property's street address (text, required)
- **Secondary field**: `landlordName` — name of the landlord/property manager (text, required)
- **Submitter email**: `submitterEmail` — required, email format
- **Description field**: `description` — free-text description of the unit (required, must be > 25 characters)
- **Category** (dropdown, 4 options): Studio / 1 Bedroom / 2 Bedroom / 3+ Bedroom
